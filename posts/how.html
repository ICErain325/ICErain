这个站点是怎么搭起来的

2026-11-01 · 约 2 分钟

整个站点只有几样东西：HTML 文件、一个 CSS 文件、一个 SVG 图标。没有 package.json，没有构建命令，改完保存，刷新就能看到。

结构

site/
├── index.html          # 首页
├── about.html          # 关于
├── 404.html            # 找不到页面时的兜底
├── favicon.svg         # 站点图标
├── assets/
│   └── style.css       # 全站样式
└── posts/
    ├── hello.html
    └── how.html

为什么不用框架

框架解决的是「内容多、要复用、要自动化」的问题。在只有几页的阶段，框架带来的配置成本比它省下的还多。等文章超过二三十篇、开始嫌复制粘贴烦了，再换 Hugo 或 Astro，把现有 HTML 迁过去也不难。

部署

把整个目录推到 GitHub，然后在 Cloudflare Pages 里连上这个仓库：构建命令留空，输出目录填 /，点一下 Deploy。之后每次 git push，它会自动重新发布，通常一两分钟上线。

成本是零。唯一的固定支出是域名，一年几十块。
